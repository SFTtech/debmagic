# Next: lint inspectables

**Status**: slices 1 (Dsc) and 3 (Control files) done. See [ADR 0044](docs/adr/0044-rules-may-read-dsc.md) and [ADR 0045](docs/adr/0045-binary-package-control-files-is-a-file-tree.md).

**Related**: [What lintian rules need to inspect](docs/research/lintian-rule-information-access.md), [import a lintian Rule](docs/develop/import-lintian-rule.md), leftover in [TODO-source-package-parity.md](TODO-source-package-parity.md).

## Goal

Grow the Rule-facing inspectables — one seam per slice, one forcing Tag, native tests plus Parity for that Tag. Rules that already fit Debian control, today's File tree, or File type stay out.

## Work

1. [x] **Dsc** — Expose the parsed `.dsc` paragraph on SourceContext (absent on a Source tree). Forcing Tag: `required-field` (LN0001 `.dsc` extras; Source-package Parity for `generic-empty`). Do not invent Dsc from patched Debian control. ADR 0044: Rules may read Dsc; extract identity stays private.
2. [~] **File-tree metadata** — Entry grows mode, owner, size, and symlink target. Host trees and Data files both emit directory and symlink kinds (Data files are regular files only today). **Done so far**: symlink target on host trees and Data files; Data files emit directories and symlinks; `package-contains-unsafe-symlink` is LN0006 with both Binary Parity recipes. **Also done**: Binary-package Data files emit tar hardlinks (content of the link target) and keep backslashes in member names. **Mode done** ([ADR 0046](docs/adr/0046-entry-carries-mode-hardlink-target-and-raw-name.md)): `Entry::mode()` (permission bits `0o7777` from the tar header for Data files and Control files, from metadata on host File trees) and `Entry::is_executable_file()`; forcing Tag `non-standard-executable-perm` is LN0700 (2 Binary recipes). **Hardlink target done**: `Entry::hardlink_target()` (the tar header's link name, normalized like member paths; `None` on host trees); forcing Tag `package-contains-hardlink` is LN0701 (3 Binary recipes; the Rule applies lintian's hardlink calibration). **Raw names done**: the tar reader keeps member names (and hardlink targets) as raw bytes, so a name that is not UTF-8 reaches Rules as a `PathBuf` with those bytes; such a pointer prints as its bytes read as Latin-1, as lintian does. Forcing Tag `shipped-file-without-utf8-name` is LN0702 (2 Binary recipes). **Left**: owner, size, each when a forcing Tag needs it. The executable bit is mode, not File type. Forcing Tag: `package-contains-unsafe-symlink` (Binary; 2 recipes). Same seam, Source-side oracle: `wayward-symbolic-link-target-in-source` / `absolute-symbolic-link-target-in-source` (`cruft-unsafe-symlinks`).

7. [x] **Interpreter table** — Vendored, lintian-2.139.0-pinned map from shebang interpreter to Depends package.
