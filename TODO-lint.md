## Goal

2. [~] **File-tree metadata** — Entry grows mode, owner, size, and symlink target. Host trees and Data files both emit directory and symlink kinds (Data files are regular files only today). **Done so far**: symlink target on host trees and Data files; Data files emit directories and symlinks; `package-contains-unsafe-symlink` is LN0006 with both Binary Parity recipes. **Also done**: Binary-package Data files emit tar hardlinks (content of the link target) and keep backslashes in member names. **Mode done** ([ADR 0046](docs/adr/0046-entry-carries-mode-hardlink-target-and-raw-name.md)): `Entry::mode()` (permission bits `0o7777` from the tar header for Data files and Control files, from metadata on host File trees) and `Entry::is_executable_file()`; forcing Tag `non-standard-executable-perm` is LN0700 (2 Binary recipes). **Hardlink target done**: `Entry::hardlink_target()` (the tar header's link name, normalized like member paths; `None` on host trees); forcing Tag `package-contains-hardlink` is LN0701 (3 Binary recipes; the Rule applies lintian's hardlink calibration). **Raw names done**: the tar reader keeps member names (and hardlink targets) as raw bytes, so a name that is not UTF-8 reaches Rules as a `PathBuf` with those bytes; such a pointer prints as its bytes read as Latin-1, as lintian does. Forcing Tag `shipped-file-without-utf8-name` is LN0702 (2 Binary recipes). **Mtime done**: `Entry::mtime()` (seconds from the tar header; `None` on host trees) and `Entry::mtime_date()` (`YYYY-MM-DD` in UTC, lintian's `date`); forcing Tag `package-contains-ancient-file` is LN1382 (2 Binary recipes); `orig-tarball-contains-ancient-file` is skipped: orig files are extracted to a host tree, which has no header mtime. **Left**: owner, size, each when a forcing Tag needs it. The executable bit is mode, not File type. Forcing Tag: `package-contains-unsafe-symlink` (Binary; 2 recipes). Same seam, Source-side oracle: `wayward-symbolic-link-target-in-source` / `absolute-symbolic-link-target-in-source` (`cruft-unsafe-symlinks`).
